API

Shynet provides a simple API that you can use to pull data programmatically. You can access this data via this URL:

{{script_protocol}}{{request.host}}{{ url_for('api.services') }}?uuid={{object.uuid}}

There are 2 optional query parameters:

  • startDate — to set the start date (in format YYYY-MM-DD)
  • endDate — to set the end date (in format YYYY-MM-DD)

Example using cURL:

curl -H 'Authorization: Token (your API token, available on security page)' '{{script_protocol}}{{request.host}}{{ url_for('api.services') }}?uuid={{object.uuid}}&startDate=2021-01-01&endDate=2050-01-01'
